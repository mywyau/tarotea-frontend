Brush artwork derived from Make Me a Hanzi by Shaunak Kishore and contributors,
using the Arphic brush fonts. Copyright (C) 1999 Arphic Technology Co., Ltd.
https://github.com/skishore/makemeahanzi/blob/bddc96d41bef78427ed0e034e9f7e31d71fd1b92/graphics.txt

Taro Tea selected, combined and repositioned individual stroke outlines and
their median paths. Each JSON file names its source components and modification.
The editable files are available here as lowercase hexadecimal Unicode code
points followed by .json. For example, 咗 is 5497.json.
